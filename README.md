# 📒 Контактная книга

> Настольное приложение для управления личными и рабочими контактами  
> **Python 3 + Tkinter | ООП архитектура | JSON хранилище**

---

## 📋 О проекте

**Контактная книга** — учебный проект, разработанный в рамках курса по программированию.  
Приложение позволяет хранить, искать и управлять контактами двух типов: личными и рабочими.

### Цель проекта
Разработать удобное графическое приложение для управления контактами с применением принципов объектно-ориентированного программирования.

### Актуальность
Существующие адресные книги привязаны к облачным сервисам и требуют интернета. Наше приложение работает полностью офлайн — данные хранятся локально на компьютере пользователя.

## ✨ Функционал

| Функция | Описание |
|---------|----------|
| ➕ Добавление | Создание личного или рабочего контакта через форму |
| 👁️ Просмотр | Список всех контактов + панель с подробной информацией |

| 🔍 Поиск | Фильтрация по имени, фамилии, телефону и email в реальном времени |

## 🏗️ Архитектура проекта

```
contact-book/
├── app.py        — Главное окно приложения (ContactApp)
├── models.py     — Модели данных (Contact, PersonalContact, BusinessContact)
├── manager.py    — Бизнес-логика (ContactManager)
├── storage.py    — Работа с файлами (FileStorage)
├── dialog.py     — Диалог создания/редактирования (ContactDialog)
└── contacts.json — База данных (создаётся автоматически)
```

### Диаграмма классов

```
Contact  (базовый класс)
│   ├── id, first_name, last_name, phone, email, created_at
│   ├── get_full_name()
│   ├── get_type_label()        ← полиморфизм
│   ├── get_display_info()      ← полиморфизм
│   ├── matches_search()
│   └── to_dict() / from_dict()
│
├── PersonalContact  (наследует Contact)
│   ├── birthday, address
│   ├── get_type_label() → "Личный"
│   └── get_display_info() → телефон + день рождения
│
└── BusinessContact  (наследует Contact)
    ├── company, position
    ├── get_type_label() → "Рабочий"
    └── get_display_info() → телефон + компания

FileStorage
│   ├── save(contacts) → JSON
│   └── load() → List[Contact]

ContactManager
│   ├── get_all(), search(query)
│   ├── add(contact), update(id, contact)
│   └── delete(id), get_by_id(id)
```

### Применённые принципы ООП

- 🔒 **Инкапсуляция** — данные контакта скрыты внутри классов
- 🧬 **Наследование** — `PersonalContact` и `BusinessContact` наследуют `Contact`
- 🔄 **Полиморфизм** — методы `get_type_label()` и `get_display_info()` переопределены в подклассах
- 🧩 **Единственная ответственность** — каждый класс отвечает только за свою задачу
- 🔗 **Изоляция данных** — работа с файлом только в `FileStorage`

## 🚀 Запуск приложения

### Требования
- Python 3.7 или выше
- Дополнительные библиотеки **не нужны** (только стандартная библиотека Python)

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/contact-book.git

# 2. Перейти в папку проекта
cd contact-book

# 3. Запустить приложение
python app.py
```
